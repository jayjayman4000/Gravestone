Use official publishers, check the exact equipment model and applicable terms, and keep the original files and a separate private backup. Transfer the files to this archive when ready.

Optional network & downloads

The live image starts offline every boot, including with persistence. To connect now, enable networking and use the native NetworkManager screen for Wi-Fi or wired connections. Passwords stay in the native screen, not this web app. This requires a keyboard (Tab, arrow keys, Enter); choose Activate a connection, then Back / Quit to return.

Network status not checked.

Opens a normal Firefox window with its own profile and address bar. Visit an official publisher, check applicable terms, and save an authorized PDF. Downloads go to /home/user/Downloads (Home → Downloads). If a PDF opens in Firefox, use its Download button. Close the browser window with its × or Alt+F4 to return here; the archive stays open behind it. Alt+Tab switches between windows.

Then choose a local PDF below. In the file chooser choose Home → Downloads, or press Ctrl+L and enter /home/user/Downloads. Enter a title and import. Choose Go offline when finished; reading/import/search continue locally. Downloads are not imported automatically and may disappear at shutdown without verified persistence. Keep a separate backup. Network connections/passwords may persist with root-union persistence, but networking is still off at each boot.

If a publisher opens a new browser window, close all download-browser windows before returning. Prefer the publisher’s actual PDF download link or the PDF viewer’s Download button, not Save Page As for an HTML page.

Import a personally acquired PDF

Personal imports are not encrypted. Anyone with system access can read them. Originals, provenance hashes and unverified search text stay in the configured private data directory, not the public collection. Image-only PDFs need external OCR for search. No USB reboot persistence is promised.

The notebook/maps backup tool does not include personal PDFs. Keep your original downloads and a separate private backup of the personal directory.
