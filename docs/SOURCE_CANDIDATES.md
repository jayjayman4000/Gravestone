# Higher-priority source candidates and admission limits

Editorial source-selection record, not installed survival guidance. These entries do not add documents to the offline catalog or certify completeness, currency, clinical suitability, or reuse rights.

The public base image should prefer identifiable, authoritative source publishers, appropriate audience, complete context, edition/update information, and a verified redistribution basis. Free web access is not a reproduction license. Private import should accept only files the user is authorized to possess and use offline; purchasing a subscription is not blanket permission to download or redistribute its content.

## Resource-limited emergency care — WHO / ICRC

- Official publication overview: https://www.who.int/publications-detail-redirect/basic-emergency-care-approach-to-the-acutely-ill-and-injured
- Official program: https://www.who.int/teams/integrated-health-services/clinical-services-and-systems/emergency-and-critical-care/bec
- Official-hosted workbook candidate: https://hlh.who.int/docs/librariesprovider4/hlh-documents/who-icrc-basic-emergency-care.pdf?sfvrsn=4460e22e_5
- The program describes its audience as first-contact healthcare providers managing acute illness/injury with limited resources, not untrained lay readers.
- The indexed 2018 workbook identifies CC BY-NC-SA 3.0 IGO. Admission still requires checking the complete actual original and all included third-party credits, attribution/share-alike/noncommercial conditions, and suitability for the intended public distribution. A general MIT software license must not relicense the workbook.
- The current publisher overview identifies presentation updates in December 2025 and postpartum-haemorrhage changes in November 2025. Do not present an older static workbook as the entire current program, or silently synthesize it with newer clinical guidance.
- Admission status: **candidate only; not installed**. No clinical instructions were generated or substituted for this work.

## Vehicle repair — Haynes

- Official digital-products terms: https://us.haynes.com/pages/terms-conditions-of-digital-manuals
- The terms identify personal/noncommercial subscription use and restrict reproduction, distribution and copying/downloading beyond specifically permitted use; consent is required for public redistribution.
- Admission status: **not bundled**. Do not scrape subscription pages, bypass access controls, or treat a subscription/ownership as permission for a cloneable public library.
- An individually authorized offline file or explicit publisher permission can be evaluated separately. Manufacturer-authorized manuals and clearly redistributable technical references should be researched by actual vehicle/equipment scope; no single generic manual covers all vehicles.

## UI implications

- Empty First Aid, Repair, or other topic categories must identify the actual installed inventory, not pretend a candidate or requested topic is present.
- A search example is not a claim that an emergency procedure exists in the collection.
- Source-only, mechanically extracted excerpts and exact original-page links remain the selected behavior. No AI-written action summaries or fabricated replacement procedures are allowed.
- Retain edition/audience/rights details in source information without repeating large legal or development boxes on every home/result card.
