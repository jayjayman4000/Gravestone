## Implemented behavior

- Homepage/header/footer use responsive, aligned gutters instead of a fixed desktop width cap. The existing palettes and civilian layout are preserved. Desktop text scales to 18 px at wide viewports. No artificial screen aspect ratio is imposed.
- Search requires all meaningful query words together in an untouched preview for short queries. Queries of four or more meaningful words may miss one word; the card explicitly names missing words, including negation. One shared extraction notice labels all source previews as unverified, and source edition is visible when provided. Keyword overlap is not semantic proof, safety verification or evidence of complete topic coverage.
- Lower-coverage matches are separate, collapsed **Partial keyword matches · may be unrelated** results, not promoted into primary repair results. The frontend displays backend limits and library-gap messages. Exact original-source excerpts and physical-page links are retained.
- Battery/storage refreshes every 15 seconds, with a five-second request deadline and no overlapping requests. Hidden-page work is cancelled; return/focus triggers refresh. Unavailable, stale and paused readings are labeled honestly. Battery status comes from the reported status rather than a contradictory legacy charging flag.
- An opt-in local AI overview is separate from original rendering, page Copy and the notebook. It currently attempts **one brief point** from at most two extracted physical-page fragments (first 1,800 characters each), not a full-document summary. Every meaningful original query word must occur in each supplied bounded fragment; unsupported subjects return `coverage-gap` without inference. Candidate eligibility is checked before ranking/selection. It discloses limited scope, a possible two-minute wait, unverified generation and exact quoted evidence. Invalid quotes/pages/schema fail closed without substitute advice. Browser cancellation does not guarantee inference cancellation. The process-local overview lock does not serialize keyword-expansion requests or all model-server work.
- The overview scrolls independently within 30% of viewport height. Citation clicks collapse it and navigate to the cited original page; stale citations cannot affect another document or a newer generation. Original reading and visible Back remain available.
